# CodeNova Data Science Internship – Batch 01

Welcome to my **CodeNova Data Science Internship – Batch 01** project repository!

This repository contains the tasks I completed as part of the internship program. These projects helped me gain practical experience in Python programming, data analysis, data cleaning, and data visualization.

## 📂 Projects

### Task 1: Sales Data Analysis
**Objective:** Analyze sales data to identify business insights and trends.

**Key Activities:**
- Analyzed sales, profit, and quantity.
- Examined monthly and quarterly sales trends.
- Compared performance across regions, categories, and customer segments.
- Created visualizations to communicate insights.

**Technologies:** Python, Pandas, Matplotlib, Seaborn.

📁 Project Folder: `Task-1-Sales-Data-Analysis/`

### Task 2: Data Cleaning Report
**Objective:** Improve data quality and prepare a dataset for reliable analysis.

**Key Activities:**
- Identified missing values and duplicate records.
- Checked and corrected data types.
- Detected potential outliers using the IQR method.
- Handled invalid and missing data.
- Generated before-and-after statistics and a cleaning audit report.

**Technologies:** Python, Pandas, NumPy.

📁 Project Folder: `Task-2-Data-Cleaning/`
